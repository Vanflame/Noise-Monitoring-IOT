● Classroom Noise Monitor

quiet, please.
the light says so.

An ESP32 with an I2S microphone estimates classroom noise in real time and shows it on a traffic-light indicator, escalating warnings while it stays loud. It is offline-first, syncs to the cloud, and only records short clips on major events.

  • ESP32
  • INMP441 (I2S)
  • Arduino / C++
  • SD + RTC
  • Supabase

01 / Features

what it actually does.

01

Traffic light

Green, yellow and red feedback anyone can read at a glance.

02

Smart escalation

Smoothing, hysteresis and timed warnings cut false alarms.

03

Privacy-first

No live listening; only 5-second clips on major events.

04

Offline-first

Events and dB series buffer to SD, then sync later.

05

On-device admin

Wi-Fi setup, thresholds, LEDs, audio tests and diagnostics.

06

Cloud dashboard

Incidents and audio sync to Supabase with role-based access.
